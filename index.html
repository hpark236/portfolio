arbline.vercel.app ↗Polymarket · Kalshi · DraftKings

ArblinePrediction markets vs the sportsbook, priced to the cent.

Every upcoming NFL, MLB, NBA and NHL game on Polymarket, Kalshi and DraftKings, converted to one unit: the all-in cost of a claim that pays $1 if a team wins. If the cheapest claims on both sides sum to under $1, the payout is locked.

The hard part is honesty. Each venue has its own team codes, fee curve and order book, so a quote is only real once fees are in and depth is checked. Opening a game walks both live order books together and reports what would actually fill.

Stack
Node serverless, vanilla JS, no API keys
Math
de-vig, taker-fee curves, depth walk, equal-payout staking
Tests
7 unit tests on odds, fees and matching

coin-vitals.vercel.app ↗Solana · Ethereum · Base · BNB · Arbitrum

VitalsA memecoin health check that shows its working.

Paste a token address. Vitals reads the contract, the pools and the holder list and returns a 0 to 100 grade, with every deduction tied to a piece of evidence: live mint or freeze authority, honeypot simulation, LP locks, top-wallet concentration, deployer-linked wallets, sell pressure, and how far a $10K exit would move the price.

The hard part is weighting. A great chart cannot save a token whose freeze authority is live, so disqualifying findings cap the score outright instead of being averaged away.

Data
DexScreener, RugCheck, GoPlus, GeckoTerminal
Math
Lorenz curve, Gini, HHI, x·y=k exit slippage
Tests
6 unit tests on the scoring model

secp-lab.vercel.app ↗no crypto libraries

Curve Labsecp256k1, Keccak, ECDSA, Schnorr and Shamir, by hand.

The cryptography under every Bitcoin and Ethereum balance, written from first principles in JavaScript BigInt: field inverses, double-and-add, Keccak-f[1600], RFC 6979 nonces, ecrecover, BIP-340 Schnorr and 3-of-5 Shamir splitting. Paste a real MetaMask signature and it names the signer.

The part people stop at is experiment four: sign two messages with the same nonce and watch the page solve for the private key, the bug behind the PS3 key leak and the 2013 Android wallet thefts.

Verified
against OpenSSL both ways, Keccak, EIP-55 and BIP-340 vectors

10 tests

amm-lab.vercel.app ↗Solidity · live mainnet reserves

AMM LabA Solidity pool, and everything that happens to it.

A Uniswap-V2-style constant-product pool in Solidity, plus a lab that reads live mainnet reserves over raw JSON-RPC and works out price impact, the bot's profit-maximising sandwich around your swap, the optimal arbitrage back to the Binance price, and impermanent loss.

The part I like is that the two halves check each other. The Hardhat tests plan a sandwich with the browser's integer math, replay it against the contract, and the attacker's on-chain profit matches the model to the wei.
